# LLVM/MLIR Builds

This repository builds LLVM/MLIR 23.1.2 for Ubuntu 24.04 of both amd64 and arm64 architecture using GitHub Actions.

The builds enable:

- MLIR
- MLIR Python bindings
- MLIR Execution Engine
- Shared libraries
- Separate ClangIR (CIR) builds

Build artifacts are uploaded automatically to the `llvm-mlir-py312-release-shared` GitHub Release.
